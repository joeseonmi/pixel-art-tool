# 픽셀아트툴

레이어·애니메이션·변형을 갖춘 개인용 픽셀아트 편집기예요. 브라우저에서 바로 열리고, 컴퓨터와 iPad에서 같이 쓸 수 있어요.

- 열기: https://joeseonmi.github.io/pixel-art-tool/
- 그림은 각 기기의 브라우저("내 작업")에 자동 저장되고, "내 작업 → GitHub 동기화"를 켜면 비공개 Gist로 기기끼리 맞춰져요.
- 이 저장소에는 편집기 페이지만 있어요. 그림 내용은 들어가지 않아요.
- `bases/` 에는 기본 마네킹 .pxproj 가 있어요 (편집기 안에도 들어 있어요).

iPad: 애플펜슬로 그리고, 손가락 하나로 화면 이동, 두 손가락으로 확대·축소, 두 손가락 탭은 실행취소, 세 손가락 탭은 다시실행.
Safari에서 공유 → "홈 화면에 추가"로 앱처럼 쓰면 좋아요.
